# AIGC Photography Director

摄影导演型 Skill。

## Concept

Most AIGC prompts describe subjects, locations and style keywords, but ignore the physical relationship between camera and subject.

This skill introduces professional photography direction:

```
Camera Position
× Camera Height
× Distance
× Direction
× Shot Size
× Foreground
× Subject Placement
```

## Goals

- Generate coherent photography series
- Create cinematic camera language
- Improve character identity consistency
- Replace meaningless style keyword stacking with real photographic decisions

## Applications

- AI portrait photography
- Character series generation
- Cinematic video prompts
- Vintage photo reconstruction
- Editorial photography

## Core Workflow

1. Analyze creative intent.
2. Design photography direction.
3. Generate shot list.
4. Plan camera spatial relationships.
5. Expand prompts.
6. Validate series consistency.
